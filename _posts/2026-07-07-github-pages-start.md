# Как я создаю личный сайт на GitHub Pages


Создание личного сайта для меня — это не только вопрос дизайна.

Это способ собрать цифровой актив, который показывает мой подход к маркетингу, аналитике и продуктовой работе.


## Зачем создавать свой сайт


Личный сайт помогает:

- показать опыт и проекты;
- структурировать знания;
- создавать собственную площадку для контента;
- формировать профессиональный бренд.


В отличие от социальных сетей, сайт полностью принадлежит мне.


## Почему GitHub Pages


Для создания сайта я выбрал GitHub Pages, потому что он позволяет:

- хранить код проекта;
- видеть историю изменений;
- использовать реальные инструменты разработки;
- бесплатно размещать статический сайт.
