# SEO Checklist

Чек-лист SEO для сайта.

Цель:
Обеспечить техническую корректность сайта, удобную индексацию и рост органического трафика.

---

# 1. Technical SEO

## Indexing

- [ ] Проверить, что сайт доступен для поисковых систем
- [ ] Настроить robots.txt
- [ ] Создать sitemap.xml
- [ ] Проверить индексацию страниц
- [ ] Удалить дубли страниц
- [ ] Настроить canonical URL


## Website structure

- [ ] Логичная структура URL
- [ ] ЧПУ-ссылки
- [ ] Нет лишней глубины вложенности
- [ ] Есть страница 404
- [ ] Настроены внутренние ссылки


---

# 2. On-page SEO


## Title

Для каждой страницы:

- [ ] Уникальный Title
- [ ] Есть основной поисковый запрос
- [ ] Длина примерно 50–60 символов


Пример:

Плохо:

"Главная"


Хорошо:

"Вячеслав Цхай — маркетолог | Исследования, стратегия и рост"


---

## Description

- [ ] Уникальный Description
- [ ] Есть ценность страницы
- [ ] Есть призыв к действию


---

## Headings

Проверить:

- [ ] Один H1 на странице
- [ ] H2 используются для структуры
- [ ] Заголовки отражают содержание


---

# 3. Content SEO


Каждый материал должен иметь:


## Search intent

Понять:

- Что пользователь хочет узнать?
- Какую проблему решает?
- Почему этот материал лучше других?


## Structure

- [ ] Заголовок
- [ ] Введение
- [ ] Основная часть
- [ ] Выводы
- [ ] Связанные материалы


## Internal links

Каждая статья должна содержать:

- [ ] Ссылки на другие материалы
- [ ] Ссылки на основные страницы сайта


---

# 4. Images SEO


Для изображений:

- [ ] Понятное название файла
- [ ] Заполнен alt
- [ ] Оптимизирован размер
- [ ] Используется WebP при необходимости


Пример:

Плохо:

image123.jpg


Хорошо:

marketing-audit-process.jpg


---

# 5. Performance


Проверить:

- [ ] Скорость загрузки
- [ ] Размер изображений
- [ ] Количество запросов
- [ ] Core Web Vitals


---

# 6. Structured Data


Использовать при необходимости:

- [ ] Person
- [ ] Article
- [ ] BreadcrumbList
- [ ] WebSite


---

# 7. Analytics


Подключить:

- [ ] Яндекс Метрика
- [ ] Google Analytics
- [ ] Search Console
- [ ] Яндекс Вебмастер


Отслеживать:

- посещения
- источники трафика
- популярные страницы
- конверсии


---

# 8. SEO Audit Process


Регулярно:


## Раз в неделю

- Проверка ошибок индексации
- Новые материалы
- Проверка позиций


## Раз в месяц

- Анализ трафика
- Анализ запросов
- Обновление старых материалов


## Раз в квартал

- Полный технический аудит
- Пересмотр структуры сайта
- Обновление стратегии


---

# 9. SEO Principles


## Пользователь важнее поисковой системы

Создавать материалы:

- которые решают проблему;
- имеют понятную структуру;
- дают практическую пользу.


## Качество важнее количества

Лучше:

10 сильных материалов

чем

100 поверхностных.


## Каждый материал должен иметь цель

Материал должен:

- привлекать аудиторию;
- показывать экспертизу;
- вести к следующему действию.
