# Design System

## 1. Принципы дизайна

Основные принципы:

- Минимализм
- Много свободного пространства
- Четкая типографика
- Фокус на содержании
- Отсутствие лишних декоративных элементов

Цель:
Создать ощущение профессионального продукта, а не обычного лендинга.

до 767px

---

# 8. Accessibility

Правила:

- контраст текста минимум WCAG AA
- alt для изображений
- понятные ссылки
- логичная структура заголовков
